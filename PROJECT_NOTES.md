## 1. Контекст и Цель Проекта

Проект представляет собой флагманский showcase-лендинг для бутик-агентства **Alberta Studio** (креативная веб-разработка, архитектура производительности, высоконагруженные интерфейсы), вдохновленный калифорнийскими студиями (San Diego / UpSunday).

### Ключевые требования:
1. **Эстетика Awwwards/FWA:** строгий темный графитовый минимализм (`#09090b`), выверенная сетка, плавный кинетический скролл, интерактивная микроанимация и 3D-центр композиции.
2. **Железобетонная производительность Core Web Vitals:** 
   - Google Lighthouse: **100 / 100 / 100 / 100** (Desktop) и **94+** (Mobile).
   - CLS (Cumulative Layout Shift) = **0.000** (абсолютно стабильная верстка с первого кадра).
   - LCP (Largest Contentful Paint) < **0.7s**.
   - INP (Interaction to Next Paint) < **50ms**.
   - TBT (Total Blocking Time) = **0ms**.
3. **Честная телеметрия в реальном времени (HUD):** отсутствие захардкоженных или искусственно заниженных чисел (никаких `0.05s`). Метрики измеряются живыми PerformanceObserver и `web-vitals`.
4. **Скульптурная 3D Монограмма («AS»):** точное соответствие оригинальному металлическому знаку `assets/logo-as-source.png` с честной 3D-экструзией, фасками, брашингом титана/цинка, динамическим изумрудным бликом и нативным альфа-каналом без черных артефактов.

## 3. Архитектура и Детали Реализации

### 3.1. 3D Монограмма («AS») — Геометрия, Топология и Рендер

- **Проблема с Earcut (Self-Intersection):**
  При 3D-экструзии сложных каллиграфических кривых в Three.js алгоритм триангуляции `Earcut` ломается, если контур самопересекается хотя бы на 0.5 пикселя. В результате вместо ленты получается сплошной черный монолит.
- **Решение топологии (True Roman Ribbon):**
  Контур литеры «S» был математически смоделирован как замкнутая каллиграфическая лента с двумя параллельными взаимонепересекающимися границами:
  - *Граница 1 (Внешний верх $\to$ нижний край центра $\to$ внутренний низ):* верхний угол засечки $(760, 140) \to$ внешняя верхняя арка $(380, 125) \to$ левое плечо $(153, 300) \to$ нижний край диагонального штриха $(560, 590) \to$ внутренняя нижняя чаша $(710, 690) \to$ правый край полки $(535, 810)$.
  - *Граница 2 (Внешний низ $\to$ верхний край центра $\to$ внутренний верх):* левый край полки $(475, 810) \to$ внешняя нижняя чаша $(630, 830) \to$ правый фланг $(817, 630) \to$ верхний край диагонального штриха $(420, 370) \to$ внутренний верхний свод $(420, 185) \to$ нижний угол засечки $(760, 380)$.
  - *Результат:* **0 самопересечений**, чистейшая триангуляция (2916 треугольников).
- **Слои и глубина экструзии:**
  - Внешнее кольцо: $Z = 0$, глубина 6, фаска 1.2.
  - Литера «А» (римская антиква): $Z = 2.5$, глубина 14, фаска 1.8.
  - Литера «S» (передний план): $Z = 8.5$, глубина 18, фаска 2.2.
- **PBR-Материал (Brushed Titanium/Zinc):**
  - Базовый тон: `0x8a92a2` (темный благородный титан/цинк).
  - Металличность: `0.82`, шероховатость: `0.22`.
  - Карта шероховатости: процедурные горизонтальные анизотропные штрихи брашинга (canvas 256×256, 700 линий).
  - Студийная среда: процедурный эквиректальный HDRI-софтбокс через `PMREMGenerator` (тени `#15171d`, софтбоксы 95% белого и изумрудного).
  - Световой эффект **Emerald Glint:** два динамических источника света (`0x10b981` и `0x34d399`), скользящих по фаскам монограммы синхронно с вращением.
  - Атмосфера: 24 кинетические частицы-искры, вращающиеся по наклонным орбитам с аддитивным свечением (`THREE.AdditiveBlending`).

### 3.3. Честная Телеметрия Core Web Vitals (Hero HUD)

В компоненте `components/ui/Hero.tsx` реализована панель телеметрии с жесткими правилами честности:
1. **LCP:**
   - Исключены микро-значения ранних скелетонов: добавлена фильтрация `effectiveMs >= 180`.
   - Страницы, восстановленные из bfcache/prerender, маркируются статусом `restored`.
   - При реальной жесткой загрузке отображаются честные **0.30s – 0.60s** (синхронно с Navigation Timing API и Lighthouse 0.6s).
2. **CLS:**
   - Отображается **0.000** с первого кадра благодаря фиксированным контейнерам (`h-[106px] min-w-0`).
3. **INP:**
   - До взаимодействия пользователя выводится пульсирующий бейдж: `Tap or click anywhere`.
   - При первом клике в любой точке экрана тайминг регистрируется мгновенно (обычно **24–48 ms**) со статусом `Captured live`.
4. **FPS:**
   - Живой спарклайн из 8 вертикальных столбиков, динамически отрисовывающий стабильность кадров (60 FPS).

## 5. Команды и Скрипты для Эксплуатации

### 5.1. Запуск и Сборка Приложения
```powershell
# Переход в рабочую папку проекта
cd "C:\Users\Andrii Zaripov\Desktop\An\Antigravity\upsunday-showcase"

# Установка зависимостей (при необходимости)

# Запуск в режиме разработки
npm run dev

# Сборка production бандла
npm run build

# Запуск скомпилированного production сервера на порту 3000
npx next start -p 3000
```

### 5.2. Скрипты 3D-Рендеринга и Ассетов (`scratch/`)
- `node scratch/render-full-sculpture-3d.js` — запускает локальный HTTP-сервер, поднимает Headless Chrome, рендерит 120 кадров Three.js (320×320) в папку `scratch/frames_3d/`, кодирует WebM VP9 alpha и MP4, генерирует side-by-side картинку и автоматически синхронизирует всё в папку `public/`.
- `node scratch/encode-videos.js` — быстрое перекодирование видео и side-by-side без повторного запуска Chrome (если кадры уже есть).
- `node scratch/test-three-geo.js` — тест топологии литер на отсутствие самопересечений (0 intersections check).

### 5.3. Аудит Производительности
```powershell

npx -y lighthouse http://localhost:3000 --chrome-flags="--headless=new" --preset=desktop --output=json --output-path="scratch/lighthouse-desktop-latest.json" --quiet
```
